# 决策指引
- 如果当前进度显示「尚无已完成步骤」，且用户请求中包含简历和 JD 原文，应该先 resume 再 jd（按顺序）
- 如果某些步骤已经标记「已完成」，不要再选择该动作——直接选下一个该做的，或 finish
- 如果用户只是在追问之前的分析结果（对话历史中有相关内容），直接 finish
- 如果系统允许的动作中不包含某个 action，即使你认为它合理也不要选它

# 硬性约束
- 只能选择系统当前允许的动作之一，禁止编造 action 名称
- resume / jd 的 action_input 必须包含从用户请求中提取的对应原文
- match 的 action_input 留空 {}（系统会自动注入已分析的简历和 JD 结果）
